# Stage 11.5 texture sample (awaiting owner approval)

Generated by `python3 tools/textures/sample.py`, using the new art-directed texture library `tools/textures/texlib.py`.
Nothing in the mod's assets has been changed yet.

The set contains 60 textures:
- 5 natural stones
- 5 ores
- 5 building blocks
- 3 wood types (planks, bark, log top, leaves)
- 5 plants
- 5 weapons
- 3 complete armour sets (4 icons + 2 model layers each)
- 3 workstations (forge front, top and side; alloy furnace; ore crusher)

| File | What it shows |
|---|---|
| `sheet_enlarged.png` | Every asset at 8×. Left is the current texture, right is the new one. |
| `sheet_native.png` | The new textures at true 1× and 2× scale. |
| `walls.png` | Stones, ores and building blocks tiled 6×4, to check how they repeat. |
| `diorama.png` | An isometric cavern corner built from the sample blocks. |
| `textures/` | The new PNG files. |

These previews come from an offline renderer. The textures have not yet been checked in the game client; that happens
after approval.
