# Soundtrack provenance and licensing

| Item | Provenance |
|---|---|
| All 73 music tracks (`assets/underdeep/sounds/music/**.ogg`) | Generated by `tools/music/compose.py` + `tools/music/synth.py` in this repository |
| Instruments | Synthesized in code (additive, FM, Karplus–Strong, modal, noise synthesis). No samples, soundfonts or recordings |
| Melodies, harmony, rhythm | Composed by deterministic rules seeded with each track id. No existing melodies were used or imitated |
| Reverb | A synthesized impulse response (decaying noise). No captured spaces |
| Encoder | ffmpeg + libvorbis (only used as tools; nothing from them ends up in the audio as content) |

The tracks are part of the Underdeep mod and share the mod's licence. Track metadata names them as "Underdeep (original,
procedurally composed)". The tracks can be regenerated byte-for-byte from the scripts with the same library versions.
They are deterministic apart from encoder version differences.

No AI music service and no external API was used. No track was derived from any copyrighted recording or score.
