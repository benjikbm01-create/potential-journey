# PRIVATE — SPOILERS

This folder holds secret lore, hidden discoveries, unique encounters and other spoiler-sensitive design.
The project owner intends to play Underdeep without knowing these secrets.

Rules for every session:
- Never quote or summarise anything from this folder in user-facing messages, commit messages,
  public docs (`docs/*.md` outside `private/`), in-game diagnostics output or code comments.
- Public docs may reference "private design material" only by file name.
- Keep spoiler content out of identifiers that players can see (item names, advancement titles) until
  the stage that reveals them in play.

Files:
- `LORE.md` — deep history of the underground world and its secrets.
- `HIDDEN_DISCOVERIES.md` — planned secret locations and unique encounters, with the stage that should
  implement each.
- `WILDLIFE.md` — rare/exceptional creatures, secret taming mechanics, hidden biology (Stage 3).
- `CIVILIZATIONS.md` — full identities, histories, customs and secrets of the eight civilizations (Stage 4).
